Curriculum Requirements for Software Architects [REQ4ARC]
2026.1-rev1-EN, 20260730

The international Software Architecture Qualification Board (iSAQB) defines curricula on several levels for software architects.

The goal of this module is to equip architects with enough requirements know-how, so that they can take educated architecture decisions, based on the real needs of stakeholders.

The terminology used in the iSAQB curricula can be found as a (freely available) ebook, published on Leanpub.

Latest Release 2026.1-rev1

The Req4Arc Curriculum is currently maintained and published in English (EN) and German (DE). Maintainers and volunteer reviewers collaborate on GitHub to improve the curriculum.
